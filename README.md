# xyz-bot – Pokelike.xyz-Bot

Bot für das Browser-Roguelike [Pokelike](https://pokelike.xyz). Er wird als **Chrome-Erweiterung** (Manifest V3) und als **Userscript** gebaut, das Userscript für die iOS-App „Userscripts“ in Safari, für Tampermonkey und für Violentmonkey.

**Stand:** Planung abgeschlossen, noch kein Bot-Code. Als Nächstes kommt Phase 1, die Aufklärung des Spiels.
